# 日常模式参考

## 偏好读取顺序

1. `amap_pref read`（daily.md）：口味与忌口 → 节奏与体力 → 预算 → 交通偏好 → 常去地点 → 随行与设备。
2. 对话里当次的临时要求**覆盖**文件里的长期偏好，冲突时以用户本次说法为准，并提示"要不要以后都这样？"。

## 行程单要点

- 每站写清：到达时间、停留时长、离开时间、到下一站车程；留 15–20 分钟缓冲。
- 餐饮点要卡在饭点（11:30–13:00 / 17:30–19:30），并优先选 `rating` 高、`cost` 符合预算的（`source=v3` 才有这两项）。
- 带老人/小孩：单次步行 ≤30 分钟、午休要有座；带宠物要确认可携宠。
- 一天的驾驶总时长超过 3 小时要主动提示，并给"减一个点"的备选。

## 常见坑

- v5 的 POI 没有评分/人均/电话；要这些字段就用 `source=v3`。
- 营业时间字段经常为空，不要编造；空就说"未提供，建议致电确认"。
- 单点周边搜索有半径上限（≤50km），行程级检索请用 `amap_corridor` 而不是超大半径单点搜索。
